### **Логика работы OpenAPI-проекта**
***
## Шаг 1. Клиент открывает каталог
Приложение отправляет запрос:
 `GET/v1/products`
 
Например:
`GET/v1/products?category=bouquets&maxPrice=5000`

Сервер:
1. Получает запрос.
2. Проверяет параметры `category` и `maxPrice`.
3. Обращается к базе данных товаров.
4. Находит подходящие букеты.
5. Возвращает результат в формате JSON.
   
Пример ответа:
```{
  "items": [
    {
      "id": "7f8c0f92-7e21-4d8d-94dc-95f034a8d501",
      "name": "Букет «Весеннее настроение»",
      "category": "bouquets",
      "price": 3490,
      "currency": "RUB",
      "color": "Розовый",
      "available": true,
      "stock": 12
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "totalItems": 1,
    "totalPages": 1
  }
}
```
## Шаг 2. Покупатель выбирает товар
После выбора букета приложение может запросить подробную информацию:
 `GET/v1/products/7f8c0f92-7e21-4d8d-94dc-95f034a8d501`

 Сервер возвращает:

- название букета;
  
- описание;
  
- цену;
  
- фотографию;
  
- доступное количество;
  
- цвет;
  
- категорию товара.

## Шаг 3. Рассчитывается доставка
  
Перед оформлением заказа приложение отправляет адрес доставки:

`POST /v1/delivery/calculate
`
`
Concept-Type: application/json
`

Тело запроса:

```{
  "address": {
    "city": "Москва",
    "street": "Тверская",
    "house": "12",
    "apartment": "45"
  }
}
```

Сервис доставки:

1.Проверяет корректность адреса.

2.Определяет зону доставки.

3.Рассчитывает стоимость.

4.Определяет примерное время доставки.

5.Возвращает результат.

Ответ:

```{
  "cost": 400,
  "currency": "RUB",
  "estimatedMinutes": 90,
  "available": true
}
```
 
 ### **Создание заказа**
***
 Для оформления заказа используется метод:
 `POST /v1/orders`

 Пример запроса:
 
 ```{
  "customerId": "6ab8f6db-b7ef-46df-ae25-b2ec5fcf6bc3",
  "items": [
    {
      "productId": "7f8c0f92-7e21-4d8d-94dc-95f034a8d501",
      "quantity": 1
    }
  ],
  "delivery": {
    "address": {
      "city": "Москва",
      "street": "Тверская",
      "house": "12",
      "apartment": "45"
    },
    "date": "2025-04-15",
    "timeSlot": "15:00-18:00",
    "recipientName": "Мария Иванова",
    "recipientPhone": "+79990001122"
  },
  "comment": "Позвонить получателю перед доставкой"
}
```

Последовательность обработки:

1.API получает запрос.

2.Проверяется структура JSON.

3.Проверяется авторизация пользователя.

4.Сервис заказов проверяет существование покупателя.

5.Проверяется наличие каждого товара.

6.Рассчитывается стоимость товаров.

7.Добавляется стоимость доставки.

8.Создаётся заказ со статусом pending.

9.Данные заказа записываются в базу.

10.Запускается платёж.

11.Клиенту возвращается созданный заказ.


Ответ сервера:

`HTTP/1.1 201 Created`
`Content-Type^: application/json`

```{
  "id": "4b7e84c9-ea4e-46ae-9910-6ed5cc1d54a8",
  "subtotal": 3490,
  "deliveryCost": 400,
  "total": 3890,
  "currency": "RUB",
  "status": "pending",
  "createdAt": "2025-04-15T10:30:00Z"
}
 ```
